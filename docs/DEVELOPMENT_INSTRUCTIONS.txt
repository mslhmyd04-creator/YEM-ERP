4. قواعد هندسية صارمة
==================================================

ممنوع وضع Business Logic داخل صفحات Flutter.

استخدم طبقات واضحة مثل:

Presentation
Application
Domain
Data
Infrastructure

كل عملية مخزون تمر عبر:

Inventory Engine

كل عملية مزامنة تمر عبر:

Sync Engine

كل عملية حساسة تسجل في:

Audit Log

لا تستخدم رقم الفاتورة Primary Key.

استخدم:

UUID

لا تخزن كلمة مرور أو Secret كنص Plain Text.

لا تضع Server Private Keys داخل APK أو EXE.

لا تجعل products.quantity هو مصدر الحقيقة الوحيد للمخزون.

Stock Ledger هو المرجع للحركات.

لا تستخدم Last-Write-Wins في:

Invoices
Journal Entries
Stock Transactions
Custody
Payments
Approved Documents

هذه العمليات تستخدم Conflict Queue.
